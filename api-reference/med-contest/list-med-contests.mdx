---

## Visão Geral

Lista paginada de todas as disputas de MED da conta autenticada, com suporte a filtros por status e datas.

## Endpoint

```http
GET /med-contest/exposes
```

## Parâmetros

<ParamField path="headers" type="object">
  <ParamField path="api_key" type="string" required>
    Chave de API para autenticação
  </ParamField>
  <ParamField path="api_secret" type="string" required>
    Secret de API para autenticação
  </ParamField>
</ParamField>

<ParamField path="query" type="object">
  <ParamField path="page" type="string" default="1">
    Página.
  </ParamField>
  <ParamField path="pageSize" type="string" default="10">
    Itens por página.
  </ParamField>
  <ParamField path="status" type="string">
    Filtra por status do MED. Valores: `WAITING_CONTENT`, `REQUESTED`, `DEFENSE_SUBMITTED`, `DEFENSE_FAILED`, `APPROVED`, `REJECTED`, `REFUNDED`, `CANCELLED`.
  </ParamField>
  <ParamField path="created_at" type="string">
    Filtra por data de criação (ISO date).
  </ParamField>
  <ParamField path="updated_at" type="string">
    Filtra por data de atualização (ISO date).
  </ParamField>
</ParamField>

## Resposta

<ResponseField name="medsContest" type="array">
  Lista de transações em disputa de MED. Cada item contém os campos da transação e um objeto aninhado `MedContest` com os dados da disputa.
</ResponseField>

<ResponseField name="total" type="number">
  Total de registros.
</ResponseField>

<ResponseField name="totalPages" type="number">
  Total de páginas.
</ResponseField>

<ResponseField name="currentPage" type="number">
  Página atual.
</ResponseField>

<ResponseField name="nextPage" type="number">
  Próxima página, ou `null`.
</ResponseField>

<ResponseField name="prevPage" type="number">
  Página anterior, ou `null`.
</ResponseField>

<ResponseField name="pageSize" type="number">
  Itens por página.
</ResponseField>

## Exemplo

**cURL**

```bash
curl --request GET \
  --url "https://gateway.3xpay.co/med-contest/exposes?page=1&pageSize=20&status=DEFENSE_SUBMITTED" \
  --header 'api_key: sua-api-key' \
  --header 'api_secret: seu-api-secret'
```
