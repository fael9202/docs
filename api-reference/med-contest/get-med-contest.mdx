title: "Detalhar Disputa de MED"
description: "Retorna os detalhes de uma disputa, incluindo o documento de evidência em base64"
---

## Visão Geral

Retorna os detalhes da disputa, incluindo o documento de evidência em **base64** (quando já tiver sido enviado via `PATCH`).

## Endpoint

```http
GET /med-contest/exposes/:medId
```

## Parâmetros

<ParamField path="headers" type="object">
  <ParamField path="api_key" type="string" required>
    Chave de API para autenticação
  </ParamField>
  <ParamField path="api_secret" type="string" required>
    Secret de API para autenticação
  </ParamField>
</ParamField>

<ParamField path="path.medId" type="integer" required>
  ID retornado por [POST /med-contest/exposes](/api-reference/med-contest/create-med-contest) ou listado em [GET /med-contest/exposes](/api-reference/med-contest/list-med-contests).
</ParamField>

## Resposta

Retorna os campos da transação acrescidos de um objeto `MedContest` com os detalhes da disputa, onde `content` traz o documento codificado em base64 (data URL).

## Exemplo

**cURL**

```bash
curl --request GET \
  --url https://gateway.3xpay.co/med-contest/exposes/1024 \
  --header 'api_key: sua-api-key' \
  --header 'api_secret: seu-api-secret'
```

**Resposta (200 OK)**

```json
{
  "id": 50231,
  "transactionId": "01a51b3e-e17d-45eb-b8a2-e2392b6b1b28",
  "status": "MED",
  "MedContest": {
    "id": 1024,
    "status": "DEFENSE_SUBMITTED",
    "content": "data:application/pdf;base64,JVBERi0xLj...",
    "description": "Comprovante de pagamento original.",
    "external_med_id": "dispute_8f3a...",
    "processor_name": "woovi",
    "retry_count": 1,
    "last_error": null,
    "created_at": "2026-05-10T13:30:00.000Z",
    "updated_at": "2026-05-10T13:32:00.000Z"
  }
}
```

## Erros Possíveis

<AccordionGroup>
  <Accordion title="400 - Validation failed (numeric string is expected)">
    O `medId` precisa ser inteiro.
  </Accordion>
  <Accordion title="400 - Esta transação não está em estado de disputa de MED">
    A transação não está mais em status `MED`.
  </Accordion>
  <Accordion title="404 - Disputa de MED não encontrada">
    Não existe disputa com esse `medId` para a conta autenticada.
  </Accordion>
</AccordionGroup>
